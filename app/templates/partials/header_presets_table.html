Как работает реальная отправка (сертификаты, CORS)

Запрос уходит прямо из вашего браузера на URL пресета — приложение сообщение не пересылает и сертификаты не получает (на сервер уходит только результат для истории отправок).

Клиентский сертификат (mTLS). Браузер подставляет его из системного хранилища ОС. Установите сертификат один раз:

  1. Конвертируйте в PKCS#12:
    • из JKS: keytool -importkeystore -srckeystore store.jks -destkeystore store.p12 -deststoretype PKCS12
    • из PEM: openssl pkcs12 -export -in cert.pem -inkey key.pem -out store.p12
  2. Импортируйте .p12: macOS — двойной клик (Связка ключей), Windows — certmgr.msc → «Личное».
  3. При первом запросе к сервису браузер покажет диалог выбора сертификата.

Самоподписанный сертификат сервера. Доверьте его CA в ОС или один раз откройте URL сервиса в браузере и примите предупреждение.

CORS. Сервис должен разрешать кросс-доменные запросы с адреса этого приложения, иначе браузер заблокирует отправку.
